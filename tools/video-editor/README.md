# AD360 – כלי עריכת וידאו עם כתוביות בעברית

כלי שורת פקודה שעושה את הדברים הבאים:

1. **מחבר** כמה קטעי וידאו מוקלטים לסרטון רציף אחד. אם הקטעים שונים בגודל, בקצב הפריימים או בפורמט השמע, הוא מאחד אותם לפורמט אחד.
2. **מתמלל** את הדיבור בעברית עם תזמון של כל מילה, בעזרת Whisper (ברירת המחדל היא מודל של ivrit.ai שאומן על עברית).
3. **מוחק השהיות, עצירות והפוגות בדיבור**, וגם קולות היסוס כמו "אממ" ו"אה". ההפסקות לא נחתכות לגמרי: נשארת נשימה קצרה כדי שהדיבור יישמע טבעי.
4. **צורב כתוביות בעברית** בקצב הדיבור, שורה אחת בכל פעם, **עד 6 מילים או 20 הברות**. הכלי מעדיף לשבור שורה בסוף משפט, בפסיק או בהפסקה בדיבור.
5. **מוסיף תמונות** על מקטע מסוים. משך הופעת התמונה נקבע לפי **מילים מתוך הטקסט** ("מהמילים X עד המילים Y"), לפי קטע מקורי או לפי זמן.
6. **מוסיף טקסטים** שמיקומם ומשך הופעתם נקבעים לפי הוראות.

## התקנה

```bash
# דרוש ffmpeg (עם libass – קיים בהתקנות הרגילות)
#   macOS:  brew install ffmpeg
#   Ubuntu: sudo apt install ffmpeg
cd tools/video-editor
pip install -r requirements.txt
```

בהרצה הראשונה המודל של Whisper יורד מ-Hugging Face (כ-1.6GB). אם יש כרטיס מסך NVIDIA, הכלי ישתמש בו אוטומטית. במחשב בלי כרטיס כזה מומלץ להוסיף `--compute-type int8`, כדי שהתמלול ירוץ מהר יותר.

**גופן:** מומלץ להוריד את הגופן [Heebo](https://fonts.google.com/specimen/Heebo), לשים את קובצי ה-`.ttf` בתיקייה `fonts/` ליד קובץ ההוראות, ולהגדיר `video.fonts_dir: fonts`. אם הגופן לא נמצא, ffmpeg בוחר גופן אחר שתומך בעברית.

## שימוש – שני שלבים (מומלץ)

### שלב 1: חיבור ותמלול

```bash
python -m ad360_video prepare clip1.mp4 clip2.mp4 clip3.mp4 -w work --compute-type int8
```

נוצרת תיקייה `work/` עם:
- `joined.mkv` – הסרטון המחובר (לפני חיתוך ההפסקות)
- `transcript.json` – כל מילה עם זמן ההתחלה והסיום שלה
- `transcript.txt` – הטקסט המלא לקריאה מהירה

**תיקון תמלול:** אפשר לפתוח את `transcript.json` ולתקן את שדה `text` של מילים שזוהו לא נכון. אין לשנות את הזמנים. הכתוביות ייבנו מהטקסט המתוקן. כדי לשפר מראש את הזיהוי של שמות ומונחים, אפשר להעביר אותם בפרמטר `--prompt "AD360, גירושין, חלוקת רכוש"`.

### שלב 2: כתיבת הוראות ובדיקה

מעתיקים את `examples/instructions.example.yaml` ועורכים אותו. כדי לראות את שורות הכתוביות ואת הזמנים בסרטון **הסופי**:

```bash
python -m ad360_video words -w work -i my-instructions.yaml
```

### שלב 3: הפקת הסרטון

```bash
python -m ad360_video render -w work -i my-instructions.yaml -o final.mp4
```

הפקודה מפיקה את `final.mp4` וגם קובץ `final.srt`, שאפשר להעלות לפלטפורמות שתומכות בכתוביות נפרדות.

### הכול בפקודה אחת

```bash
python -m ad360_video run clip1.mp4 clip2.mp4 -i my-instructions.yaml -o final.mp4
```

## קובץ ההוראות

כל הזמנים בקובץ ההוראות מתייחסים **לסרטון הסופי**, אחרי חיתוך ההפסקות. דוגמה מלאה נמצאת ב-[`examples/instructions.example.yaml`](examples/instructions.example.yaml).

### תזמון לפי מילים

| מפתח | משמעות |
|---|---|
| `words: "חלוקת רכוש"` | מהמילה הראשונה של הביטוי ועד האחרונה שבו |
| `from: "המשרד שלנו"` | מתחיל כשהביטוי נאמר. עם `from_end: true` מתחיל בסוף הביטוי |
| `to: "כל הדרך"` | מסתיים בסוף הביטוי (מחפש אחרי ה-`from`) |
| `occurrence: 2` | המופע השני של הביטוי (ל-`to` משתמשים ב-`to_occurrence`) |
| `clip: 2` | כל הקטע המקורי השני |
| `start: 3.5` / `end: 7` | זמן מוחלט בשניות |
| `duration: 2.5` | משך, כשלא מוגדר סוף |
| `lead: 0.3` / `tail: 0.5` | להקדים או להאריך את ההופעה |

החיפוש של ביטויים סלחני לשגיאות זיהוי קטנות, להבדלים בניקוד ובפיסוק, ולאות שימוש אחת בתחילת מילה (ה/ו/ב/ל/מ/ש/כ). אם ביטוי לא נמצא, מוצגת שגיאה עם ההתאמה הקרובה ביותר בתמלול.

### מיקום

אפשר להשתמש בשם מיקום: `top-left`, `top`, `top-right`, `left`, `center`, `right`, `bottom-left`, `bottom`, `bottom-right`. אפשר גם בעברית: `למעלה מימין`, `למטה`, `מרכז` וכו'.

לחלופין אפשר לתת מיקום מדויק של מרכז האלמנט, ביחס לגודל המסגרת: `{x: 0.5, y: 0.3}`.

גדלים (`width`, `font_size`, `margin`): ערך עד 1 הוא שבר מגודל המסגרת, וערך גדול מ-1 הוא בפיקסלים.

### תמונות (`images`)

```yaml
images:
  - file: logo.png          # יחסית לקובץ ההוראות; PNG שקוף נתמך
    from: "המשרד שלנו"
    to: "כל הדרך"
    position: top-right
    width: 0.3
    fade: 0.3               # שניות של הופעה והיעלמות הדרגתיות
    opacity: 1.0
```

### טקסטים (`texts`)

```yaml
texts:
  - text: "ייעוץ ראשוני ללא עלות"
    words: "דירה משותפת"
    duration: 2.5
    position: {x: 0.5, y: 0.25}
    font_size: 0.055
    color: "#FFD400"        # #RRGGBB או #RRGGBBAA (AA = אטימות)
    box: true               # רקע מאחורי הטקסט
    box_color: "#000000B0"
```

אפשר לשבור שורה בתוך הטקסט עם `\n`.

### כתוביות (`captions`) וחיתוכים (`cuts`)

| הגדרה | ברירת מחדל | הסבר |
|---|---|---|
| `captions.max_words` | 6 | מספר המילים המרבי בשורה |
| `captions.max_syllables` | 20 | מספר ההברות המרבי בשורה |
| `captions.position` | bottom | `bottom` / `middle` / `top` |
| `captions.box` | false | רקע כהה מאחורי הכתובית |
| `cuts.max_pause` | 0.30 | הפסקה ארוכה מזה (בשניות) תקוצר |
| `cuts.keep_pause` | 0.12 | כמה זמן להשאיר מהפסקה ארוכה |
| `cuts.padding` | 0.08 | שוליים לפני ואחרי כל רצף דיבור |
| `cuts.remove_fillers` | true | הסרה של "אממ", "אה" |
| `cuts.mode` | words | `words` לפי התמלול, `silence` לפי עוצמת השמע |
| `cuts.enabled` | true | `false` משאיר את הסרטון בלי חיתוכים |

**ספירת הברות:** בטקסט מנוקד הספירה מדויקת. בטקסט לא מנוקד (זה מה שהתמלול מחזיר) הכלי משתמש בהערכה, ובדרך כלל היא סוטה בהברה אחת לכל היותר למילה. מגבלת 6 המילים נאכפת תמיד.
